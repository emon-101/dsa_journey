## 🔁 Daily Routine

1. **Learn** one concept (20–30 min)
2. **Implement** it from scratch in C++ (20–30 min)
3. **Solve** 1–3 problems (30–45 min)
4. **Note** the pattern, mistake, and revisit date (10 min)
5. **Log + push** with `./scripts/log.sh`

Minimum viable day: 1 problem + a 3-line note.

## 🛠 Usage

```bash
# Create a new solution file from the template
./scripts/new_problem.sh 02-arrays-and-strings two_sum

# Compile and run it
./scripts/run.sh 02-arrays-and-strings/two_sum.cpp

# Log your day, update the streak, commit, and push
./scripts/log.sh "arrays" 2 "prefix sums"
```
